# Demo sandbox

Open `/demo` or use **Try it with sample data**. It starts with a synthetic animated scene instead of a camera and shows all six cues. Demo presets use `localStorage` keys starting with `demo:camera-fx-cues:`. **Reset demo** clears only that prefix. **Start for real** clears the demo prefix and opens the camera screen. Real presets use the separate `camera-fx-cues:` prefix and are never read or changed in demo mode.

No camera image, photo, or video is stored in either mode.
