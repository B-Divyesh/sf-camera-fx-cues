# Demo sandbox

Open `/demo` or use **Try it with sample data**. It starts with a synthetic animated scene instead of a camera and shows all six cues. Demo preferences use `localStorage` keys starting with `demo:camera-fx-cues:`. **Reset demo** clears only that prefix. **Start for real** clears the demo prefix and returns to the camera consent screen.

No camera image, photo, or video is stored in either mode.
